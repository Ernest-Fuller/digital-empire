# Free Digital Tools

Small, free, self-contained tools and checklists. Each one is a single static page: no install, no account, no network needed, and your data stays in your browser.

## How to use one

1. Open the [Releases](https://github.com/Ernest-Fuller/digital-empire/releases) page and pick a product.
2. Download the zip and unzip it.
3. Open `index.html` in any browser.

You can also host the unzipped folder on any static host (GitHub Pages, Netlify, Cloudflare Pages).
